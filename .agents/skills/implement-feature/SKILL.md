# Implement Feature

Follow the repository's `AGENTS.md` and the user's requirements.

- Inspect only the code and documentation relevant to the feature. Resolve routine choices from existing conventions; clarify consequential gaps.
- Prefer functions over classes. Use a class only when a class-based API or per-instance state requires one.
- Keep the change focused. Reuse existing patterns and put behavior with its owning module or service.
- Preserve affected contracts and failure behavior. Update related schemas or documentation when behavior changes.
- Verify in proportion to the change, review the diff, and report what changed and any remaining limitation.
