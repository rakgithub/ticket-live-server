# ADR format

Use one file per decision in the repository's established ADR directory. Prefer the next sequence number used by that directory.

```markdown
# ADR-0001: Short decision title

## Status

Accepted

## Context

The problem, constraints, and alternatives that made a decision necessary.

## Decision

The decision and its scope.

## Consequences

Benefits, costs, risks, and follow-up work that the decision creates.
```

Keep the ADR factual and concise. Link to supporting material when it helps explain the decision; do not turn the ADR into a design specification.
